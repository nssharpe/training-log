Training Log — layout mockups

Same sample data (Phase 1, Day 3) rendered three different ways. Open each on phone + desktop.

  • Mockup A — Row-per-exercise, inline prescription

    Light theme. Each exercise is a card; small prescription chip sits above the input grid. Closest match to the “Prevarsity Chest and Back” sheet.

  • Mockup B — Two-column split

    Dark theme. Left column is the prescription (sticky on desktop, collapsible on mobile); right column is today’s input. Closest to the “T&F Summer 1 - Arms” sheet.

  • Mockup C — Full phase grid / single day

    Paper-ish theme. Desktop shows the full 8-day phase with today highlighted and past days summarized. Mobile collapses to today only with a day-switcher. Closest to the original MFTK PDF layout.
